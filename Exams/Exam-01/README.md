# Exam 01 — Java Basics

**Level:** Beginner

Try each question first. Write your answer and predict the output before running the program.

## Questions

1. Print `Hello Java`.
2. Declare an `int` variable and print its value.
3. What is the difference between `==` and `.equals()` when comparing strings?
4. Create a `Student` object using a constructor.
5. Predict the output:

```java
int count = 5;
System.out.println(count++);
System.out.println(count);
```

## Solutions

Solution files are stored in the `solutions/` folder. For question 3, remember that `==` compares references for objects, while `.equals()` compares content when the class implements it accordingly.
