## How to Run Java Programs

1. Install a JDK (preferably a current LTS version).
2. Check installation: `java -version` and `javac -version`.
3. Open a terminal in the folder containing the `.java` file.
4. Compile and run, for example:

```bash
javac HelloWorld.java
java HelloWorld
```
